# 📊 Retail Sales Seasonal Dashboard

An interactive retail sales analytics dashboard built using **Python, Pandas, Plotly, and Dash**.  
The project analyzes retail sales data to understand revenue, units sold, discounts, seasonal patterns, and regional performance.

## 🚀 Project Overview

Retail businesses generate large amounts of sales data. Analyzing this data helps identify:

-  Sales trends over time
-  Revenue performance
-  Units sold
-  Regional sales performance
-  Seasonal sales patterns
-  Average discounts
-  Future sales trends using forecasting

This project converts raw retail sales data into meaningful visualizations through an interactive dashboard.

## 🎯 Objectives

- Analyze retail sales data using Python.
- Identify seasonal fluctuations in sales.
- Compare revenue across different regions and seasons.
- Analyze units sold across regions.
- Visualize sales trends over time.
- Analyze average discounts by season.
- Provide an interactive dashboard for exploring the data.

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| Python | Data analysis and dashboard development |
| Pandas | Data manipulation and analysis |
| NumPy | Numerical operations |
| Plotly | Interactive data visualization |
| Dash | Interactive dashboard |
